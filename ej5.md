# Ejercicio 5: Acreditable

## Explicación Lógica
1. **Contrato de Comportamiento:** La interfaz `Acreditable` define una capacidad (`obtenerHorasAcreditadas()`) sin imponer restricciones de herencia jerárquica.
2. **Polimorfismo:** Permite procesar de forma uniforme objetos provenientes de clases totalmente disímiles mediante la misma referencia de interfaz.
